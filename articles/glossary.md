# Glossary

## Data and design

``` r

library(easyNIS)
library(dplyr)
library(srvyr)

nis_open(nis_example(years = 2020)) |>
  nis_design(cohort = AGE >= 18, keep = AGE) |>
  summarise(sampled = unweighted(n()), weighted = survey_total())
```

In this invented adult survey domain, `sampled` counts discharges in the
cohort and `weighted` estimates the discharge total using `DISCWT`.

| Term | Meaning |
|----|----|
| National Inpatient Sample (NIS) | The HCUP sample of inpatient discharges. Before 2012, it was called the Nationwide Inpatient Sample. |
| Discharge | One inpatient stay. A person can contribute several discharges. The NIS does not link stays across time for the same person. |
| Data year | Calendar year of discharge. A release can be updated after publication. Record the revision you received. |
| Component | A file within the annual release, such as Core, Hospital, or Severity. |
| Discharge weight (`DISCWT`) | Weight used to estimate national discharge totals and other weighted quantities. |
| Trend weight (`TRENDWT`) | HCUP weight for eligible historical releases. It helps compare estimates across the 2012 redesign. |
| Stratum (`NIS_STRATUM`) | Group within which easyNIS compares hospital contributions to estimate variance. |
| Hospital cluster (`HOSP_NIS`) | Hospital identifier used as the primary sampling unit (PSU) in the [variance approximation](https://msaadasif.github.io/easyNIS/articles/nis-design.md). |
| Cohort | Discharges that meet the study inclusion criteria. |
| Survey domain | Subpopulation estimated using the original sample design. |
| Hospital placeholder | Zero contribution for a sampled hospital-year with no cohort discharges. |
| Estimand | The quantity you plan to estimate, such as average annual adult discharges. |
| Annualization | Division of all discharge weights by the number of included design years. |
| Reweighting | Multiplication of survey weights by analyst-supplied factors. The resulting totals generally lose their national count interpretation. |

## Clinical coding and costs

| Term | Meaning |
|----|----|
| Coding era | The code system in use at discharge. [2015 spans two eras](https://msaadasif.github.io/easyNIS/articles/years-and-eras.md). |
| Code slot | A numbered field that holds one diagnosis or procedure code, such as `I10_DX1`. |
| Principal diagnosis | The condition established after study to be chiefly responsible for the admission. |
| CCSR | Clinical Classifications Software Refined groups ICD-10-CM diagnoses and ICD-10-PCS procedures. easyNIS bundles the mappings. |
| Comorbidity | A condition that coexists with the condition under study. easyNIS supports Elixhauser and Charlson methods for ICD-9-CM and ICD-10-CM, with method-specific inputs. |
| Present on admission (POA) | Whether a diagnosis was present at the time of admission. The NIS has no diagnosis-level `DXPOA` fields. |
| Charge | Amount billed for the stay. |
| Cost-to-charge ratio (`CCR_NIS`) | Hospital-level multiplier that converts charges to estimated costs. |
| CPI-U | Consumer Price Index for All Urban Consumers. easyNIS uses it to express amounts in dollars of a common year. |

## Disclosure

| Term | Meaning |
|----|----|
| Primary suppression | Masking a cell because the cell violates a disclosure rule. |
| Complementary suppression | Masking another value so a primary suppressed cell cannot be recovered by subtraction. |
| Invented data | Discharges generated by [`nis_example()`](https://msaadasif.github.io/easyNIS/reference/nis_example.md) for practice. |
