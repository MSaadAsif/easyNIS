# Security and privacy

Please report security vulnerabilities privately through [GitHub Security Advisories](https://github.com/MSaadAsif/easyNIS/security/advisories/new). Do not open a public issue for a vulnerability before the maintainers have had a chance to assess it.

This includes data-privacy incidents, such as accidentally publishing licensed HCUP inputs, record-level NIS data, private paths, local validation receipts, or record-derived output. Do not include sensitive data in the advisory. Describe the type of exposure and the affected repository location without reproducing the data.

For non-sensitive bugs and feature requests, use the public GitHub issue templates.
