# License choice

The project license is GNU AGPL version 3 only (`AGPL-3.0-only`; R
package metadata uses `AGPL-3 + file LICENSE`). This is a strong
copyleft license: distribution of modified versions carries source and
same-license obligations. Section 13 adds a network-use provision: users
interacting with a modified version remotely must be offered its
Corresponding Source.

## Comparison

- [MIT](https://opensource.org/license/mit) is permissive. It allows
  reuse, modification, and distribution, subject mainly to retaining the
  copyright and permission notices.
- [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0) is also
  permissive, with express patent terms and requirements to preserve
  notices and mark changes.
- [GPLv3](https://www.gnu.org/licenses/gpl-3.0.html) uses strong
  copyleft for conveyed copies and modified versions. It does not add
  AGPLv3’s specific network-interaction source offer.
- [AGPLv3](https://www.gnu.org/licenses/agpl-3.0.html) builds on GPLv3
  and adds that source offer for users interacting remotely with a
  modified version.

This comparison summarizes license terms, not legal advice. Prior
easyNIS releases published under MIT remain licensed under the MIT grant
for those versions; this change applies to this project version and
later versions.
