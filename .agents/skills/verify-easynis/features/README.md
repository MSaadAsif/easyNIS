# easyNIS verification map

The primary user surface is the exported R API. Launch and doctor instructions
are in the parent skill. Use an isolated installed package and invented parquet
files. Evidence is kept in the reported `.audit/verify/` directory.

- [Import and validation](import-validation.md) covers the installed source package, synthetic years, raw projections, structural status and cleanup.
- [Code-set cohort flags](cohorts.md) covers user declarations, row preservation and independent R/SQL comparison.
- [Capability lookup](capabilities.md) covers the distinction between a target year and supported analysis.

Add recipes when the public API expands. Exercise all affected entry points;
report an unavailable path as unverified, and retain its blocker in the backlog.
