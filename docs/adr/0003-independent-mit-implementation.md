# Write easyNIS independently under MIT

The existing easyNRD implementation reserves all rights, while Saad chose MIT for new easyNIS code. Saad chose an independent implementation informed by the NRD design review, postponing direct copying until Ali grants compatible permission or licensing. This keeps easyNIS independently distributable and avoids making its release depend on relicensing the unfinished NRD package.
