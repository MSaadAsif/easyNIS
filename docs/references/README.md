# Local reference book

The supplied book is Hadley Wickham's *R packages*, dated June 29, 2015, with 203 PDF pages. The original was moved from Documents to `docs/references/local/r-packages.pdf` in the easyNIS checkout. Identical local copies are in the same subfolder of the easyNRD and easyNRD-public checkouts. SHA-256 checks confirmed the copies match.

The `local/` directory is ignored by Git. The book and extracted text are not distributed with easyNIS. The attached edition is useful for package principles; current commands, dependency conventions, CI, and release requirements should be checked against the [second edition](https://r-pkgs.org/), [Writing R Extensions](https://cran.r-project.org/doc/manuals/r-release/R-exts.html), and [CRAN policies](https://cran.r-project.org/web/packages/policies.html).
